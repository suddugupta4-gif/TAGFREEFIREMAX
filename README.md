# TAGFREEFIREMAX

Free Fire Esports Statistics & Tournament Tracking Platform inspired by modern competitive esports dashboards.

## Features
- **6-Match Tournament Format**: Automatic placement points, kill points, and Booyah calculations across 6 matches.
- **Official vs Unofficial Category Toggle**: Switch between official championship leagues and community scrims with animated motion UI.
- **Admin Authentication**: Built-in score editing protected by admin password (`taglevelonbro190-`).
- **Responsive Esports UI**: Dark mode layout with CSS keyframe animations, glow FX, and hover interactions.

## Quick Start
Open `index.html` in any web browser or deploy directly to **GitHub Pages** or **Render**.
